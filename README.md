# iOptimize 16e ⚡

> Full system optimizer & security monitor — built specifically for **iPhone 16e**  
> Installable as a PWA directly from Safari. No App Store needed.

[![Live Demo](https://img.shields.io/badge/demo-live-success)](https://squilltim.github.io/iphone-16e-optimizer)

---

## ✨ Features

| Tab | What it does |
|---|---|
| 📊 **Dashboard** | Live battery %, storage, network, RAM — real iOS APIs |
| 🚀 **Optimize** | One-tap optimizer, battery toggles, cache cleaner, RAM tools |
| 🛡️ **Security** | Full security scan, privacy controls, HTTPS & Wi-Fi checks |
| ⚙️ **Settings** | Dark/light mode, install guide |

---

## 📲 Install on iPhone 16e

1. Open `https://squilltim.github.io/iphone-16e-optimizer` in **Safari**
2. Tap the **Share** button (box with ↑ arrow)
3. Tap **"Add to Home Screen"**
4. Done — launches full-screen like a native app

---

## 🛠 Tech Stack

- Pure **HTML / CSS / JavaScript** — no framework, no build step
- **PWA** with Service Worker (offline support)
- Uses native browser APIs: Battery API, Storage API, Network Information API
- Deployed via **GitHub Actions → GitHub Pages**
